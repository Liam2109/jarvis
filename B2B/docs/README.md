# B2B/docs — contexte et suivi de l'agence

Documentation non-code : décisions, offres, idées, listes d'appels, journal. Pas de secrets ici.

## Fichiers clés
- `MEMOIRE-B2B.md` — état, décisions et règles à jour (contexte à lire en premier).
- `TODO-B2B.md` — ce qui reste à faire, par priorité.
- `JOURNAL-B2B.md` — une ligne par tâche notable.
- `IDEES-MASTER.md` / `IDEES-CLAUDE-CHAT.md` — idées de Liam, datées.
- `OFFRES-SITES.md`, `DEVIS-ET-OBJECTIONS.md`, `liens-paiement.md` — offres, devis type, liens Stripe.
- `KIT-RDV-15MIN.md`, `SCRIPT-APPEL-SID.md`, `APPEL-SID.md` — supports d'appel et de rendez-vous.
- `INSTAGRAM-PLAN.md` — plan de publication Instagram.
- `SOURCES-DONNEES.md` — sources de prospection autorisées et leurs limites.
- `liste-appels-AAAA-MM-JJ.md`, `sid/` — listes d'appels générées jour par jour (données, pas de la doc).
