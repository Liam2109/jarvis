# Script de closing de Liam (au téléphone ou en visio)

Règles : aucun chiffre inventé, aucune promesse de résultat Google, aucun délai non confirmé, rien sur la rétractation tant que le texte n'est pas relu. Je dis ce qui sera écrit sur la page de paiement.

## Déroulé
1. Écouter (comment les clients le trouvent, ce qui lui manque), montrer l'exemple du métier.
2. Prix du site complet : « Le site complet, c'est 994 euros, une seule fois. Ensuite, 49 euros par mois pour l'hébergement, la maintenance, le support et le nom de domaine, et le premier mois est offert. »
3. Si « trop cher » : « Si le site complet est trop pour vous, la page à 595 euros a le même soin, tout sur une seule page. Même formule : 595 euros une seule fois, puis 49 euros par mois, premier mois offert. »
4. Question de closing : « Qu'est-ce qui nous empêche de travailler ensemble ? » Écouter, répondre à ça seulement.
5. E-mail et lien : « Quelle adresse e-mail ? Je vous envoie le devis et le lien de paiement tout de suite. »
6. Pendant qu'il paie : expliquer la suite (photos, couleurs, logo, vrais avis, particularités de son métier). Ne donne une date de mise en ligne que si elle est confirmée.

## Phrases fixes (à dire avant le paiement)
- Prix : « La création, c'est [595 ou 994] euros, une seule fois. Ensuite, 49 euros par mois pour l'hébergement, la maintenance, le support et le nom de domaine, et le premier mois est offert. »
- Arrêt : « Vous pouvez arrêter les 49 euros par mois quand vous voulez. L'arrêt prend effet à la fin du mois payé. Le site reste en ligne tel quel, mais je ne le modifie plus et il n'y a plus de support. »
- Domaine : « Le nom de domaine est à votre nom. Si vous partez, je vous donne ce qu'il faut pour le transférer. » (à confirmer avec le bureau d'enregistrement avant de le dire)
- Page de paiement : « Sur la page de paiement, vous verrez exactement ça : [595 ou 994] euros aujourd'hui, puis 49 euros par mois à partir du mois suivant. »

## Objection « C'est trop cher »
« Je comprends. [595 ou 994] euros une seule fois pour la création, puis 49 euros par mois que vous pouvez arrêter quand vous voulez. Si un seul chantier obtenu grâce à la page rembourse, ça vaut le coup. Je ne peux pas vous promettre ce chiffre. Qu'est-ce qui vous gêne le plus : le montant ou le mensuel ? »

- Je n'ai jamais livré de site de plusieurs pages : pour le site complet, je confirme le contenu précis par écrit dans le devis avant de prendre le paiement.
- Un « Je dois réfléchir » : devis par e-mail, rappel à un jour précis, noté dans le suivi.
