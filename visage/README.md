# visage — interface web de Jarvis

Pages HTML/JS locales (coffre, tableau de bord, salle de marché) servies par Jarvis, sans appel réseau externe ni `innerHTML` sur des données.

## Fichiers clés
- `index.html` — page de l'orbe/visage.
- `pilotage.html` + `pilotage.js` — tableau de bord (Aperçu, Initiatives, Missions, Tâches, Analytics).
- `marche.html` — salle de marché.
- `widgets.js` — barre de widgets, menu, panneaux Configuration/Capacités, partagé entre pages.
- `lib/` — bibliothèques JS (three.js).
- `vues/` — vues 3D/visuelles (horloge, monument-3d).
